# База знаний

Взята открытая вселенная **Star Wars** (`starwars.fandom.com`): 38 статей о персонажах, планетах, технике, организациях, расах и концепциях. Модель знает этот мир по обучающим данным, поэтому все узнаваемые термины заменены и получилась вымышленная вселенная **Aetherium Concord**.

## Как заменяли

- Словарь `terms_map.json` хранит соответствия «исходный термин → вымышленный».
- Заменяются имена, фамилии, прозвища, планеты, расы, техника, организации, титулы и даты (`BBY` → `BKC`).
- Длинные термины обрабатываются раньше коротких: «Darth Vader» → «Xarn Velgor», а не «Darth Velgor».
- Регистр сохраняется; слова вроде `Force` и `Solo` заменяются только с точным регистром, чтобы не ломать обычный текст.
- Замены не применяются к уже заменённому тексту.

Скрипт замены — `tools/build_knowledge_base.py`. Он же скачивает статьи и очищает их от разметки.
