# База знаний для RAG-бота

Учебная база знаний для проверки RAG: мир, который языковая модель не могла видеть при обучении. Взята открытая вселенная **Star Wars** (`starwars.fandom.com`), из неё удалены все узнаваемые имена и названия, а текст переписан в терминах вымышленной вселенной **Aetherium Concord**.

## Что в папке

| Файл | Назначение |
|---|---|
| `*.md` | 38 документов, по одному на сущность: персонажи, планеты, техника, организации, концепции |
| `terms_map.json` | словарь замен «исходный термин → вымышленный» с пояснением к вселенной |
| `index.json` | список документов с категориями для загрузки в RAG |
| `README.md` | это описание |

Документы покрывают пять категорий: персонажи (14), планеты (8), техника (8), организации (6), концепции и расы (2). Объём — от 1,5 до 9 тыс. символов на документ.

## Зачем заменять термины

Star Wars многократно попадала в обучающие данные, поэтому на вопрос «кто такой Дарт Вейдер» модель ответит по памяти, не обращаясь к индексу. Если заменить имена, планет и техники, у модели не остаётся знаний о мире: ответить можно только по загруженным документам. Это воспроизводит ситуацию с реальной корпоративной базой, которой нет в открытых источниках.

## Как устроена замена

Логика в `tools/build_knowledge_base.mjs`:

1. **Загрузка.** 38 статей скачиваются через MediaWiki API Fandom в виде wikitext.
2. **Очистка.** Удаляются шаблоны, сноски, таблицы, изображения, категории и служебные разделы (`Behind the scenes`, `Sources`, `Appearances`). Ссылки превращаются в текст, заголовки — в Markdown. Строки с упоминаниями реального мира (franchise, film, Lucasfilm) отбрасываются.
3. **Замена.** Все термины из `terms_map.json` заменяются одним проходом по регулярному выражению.
4. **Сохранение.** Каждый документ обрезается до 9 тыс. символов по границе абзаца и пишется в `knowledge_base/<slug>.md`.

Ключевые свойства замены:

- **Длинные термины приоритетнее.** «Darth Vader» заменяется раньше, чем «Vader», поэтому получается «Xarn Velgor», а не «Darth Velgor».
- **Нет каскада.** Замены не применяются к уже заменённому тексту: вымышленные имена не могут быть заменены повторно.
- **Регистр сохраняется.** «Jedi» → «Fluxadept», «jedi» → «fluxadept», «JEDI» → «FLUXADEPT».
- **Отдельный список чувствительных терминов.** Слова вроде `Force`, `Solo`, `Mace`, `Bail`, `Wedge`, `Basic` заменяются только с точным регистром, чтобы не портить обычный английский текст.
- **Заменяются не только имена.** Планеты, расы, техника, организации, титулы, события и единицы времени (`BBY` → `BKC`).

## Структура `terms_map.json`

```json
{
  "universe": { "source": "...", "target": "...", "why": "..." },
  "rules": { "...": "..." },
  "case_sensitive": ["Force", "Solo"],
  "categories": {
    "characters": { "Anakin Skywalker": "Aran Velmor" },
    "planets": { "Tatooine": "Sorrhas" },
    "species": { "Wookiee": "Gorran" },
    "technology": { "lightsaber": "fluxblade" },
    "organizations": { "Jedi": "Fluxadept" },
    "events": { "BBY": "BKC" }
  }
}
```

Скрипт объединяет все категории в один словарь, поэтому категории нужны только для читаемости. Всего в словаре 736 терминов.

## Как пересобрать

```bash
node tools/build_knowledge_base.mjs   # скачать и пересобрать документы
node tools/validate_kb.mjs            # проверить, что исходные термины не остались
```

`validate_kb.mjs` ищет в готовых документах названия из исходной вселенной и завершается с ошибкой, если что-то найдено.

## Важно

- `terms_map.json` содержит исходные названия, поэтому **не включайте его в индекс RAG** и не подавайте модели как документ. Для индексации используйте только `*.md`.
- Тексты — производные от материалов Fandom (CC BY-SA). Они нужны для учебного задания и не предназначены для публикации.
