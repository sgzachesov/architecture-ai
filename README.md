# RAG-бот для QuantumForge Software

Репозиторий проектной работы 7 спринта: корпоративный RAG-бот по внутренней базе знаний.

## Материалы

- [`docs/task-1-research.md`](docs/task-1-research.md) — полный отчёт по заданию 1: сравнение LLM, эмбеддингов и векторных хранилищ, конфигурация сервера, варианты решения и рекомендация.
- [`Project_template.md`](Project_template.md) — краткие ответы по заданию 1 для сдачи.

## Кратко о выбранном стеке

| Слой | Выбор |
|---|---|
| LLM | Qwen2.5-32B-Instruct AWQ (vLLM) + GPT-4o-mini для public/internal |
| Эмбеддинги | BAAI/bge-m3 |
| Векторная БД | FAISS (отдельные индексы по доменам доступа) |
| Реранкер | bge-reranker-v2-m3 |
| Сервер | 16 vCPU / 64 GB RAM / 1×L40S 48 GB / 1 TB NVMe |

## Ветка

Работа выполняется в ветке `RAG`.
